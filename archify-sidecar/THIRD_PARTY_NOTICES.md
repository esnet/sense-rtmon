### The one file that is not upstream's

`archify-cli/renderers/shared/generated-brand-marks.mjs` is **deliberately
emptied** here and is not upstream's file. Upstream ships ~160 KB of
third-party brand logos there. Per upstream's own `THIRD_PARTY_NOTICES.md`
those include **CC-BY-NC-SA-4.0** (Vue.js - NonCommercial _and_ ShareAlike),
CC-BY-SA-4.0 (Rust), CC-BY-SA-3.0 (Jenkins) and CC-BY-4.0 (Angular) artwork,
plus trademarked marks usable only under their brand guidelines. None of it
is reachable from the RTMon integration, which never sets a `brand` field on
a component, so keeping it would have pushed NonCommercial-licensed artwork
into this repository and every image for no functional gain. The file exports
an empty `BRAND_MARKS` array; `brand-marks.mjs` imports it, so it has to
exist.

**When re-vendoring, do not restore that file from upstream** unless the
individual marks have been cleared - the NonCommercial one especially. The
procedure in `README.md` re-empties it.
